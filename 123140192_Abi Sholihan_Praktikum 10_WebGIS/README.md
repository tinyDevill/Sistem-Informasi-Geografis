# WebGIS Praktikum 9 - Tema Gelap

Project WebGIS untuk fasilitas dan deteksi objek dengan tampilan latar belakang hitam.

## Fitur
- Login halaman gelap
- WebGIS fasilitas dengan basemap dark mode
- WebGIS deteksi dengan latar hitam dan overlay gambar + GeoJSON
- Deteksi hasil YOLO + tiling ditampilkan pada koordinat pixel

## File penting
- `public/detections.geojson`
- `public/Test.png`

## Jalankan
```bash
npm install
npm run dev
```

## Route
- `/` -> WebGIS utama
- `/deteksi` -> WebGIS deteksi
